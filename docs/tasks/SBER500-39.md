## Бизнес-результат
Антон сможет писать свободно: LLM выбирает смысл каждого текста, а не набор keyword/regex правил. Это изменение требования Антона 07.10.2026, не гипотеза о росте метрик. Код проверяет схему, владельца, актуальность и допустимость действия; модель не получает инструменты/DB IDs.
## Критерии приёмки
Все message.text, команды, тексты кнопок, цифры, onboarding/pending и STT → модель. Callback_query остаётся прямым выбором. Жалоба, read/clarify и ошибки модели не меняют работу/задачи/таймер/pending. Отдых40/90 в paused уточняет срок от pausedAt, не возвращает к работе; повтор не переносит срок. Продолжение — отдельное намерение. Неоднозначность → вопрос. Старый intent fallback отсутствует.
## Что сделано ботом — локальная реализация проверена
Единый LLM ingress охватывает каждый текст: команды, первый ввод, onboarding, цифры, ответы на текущий вопрос, тексты кнопок и голос после STT. Модель выбирает типизированное действие; код проверяет схему, владельца, свежесть и допустимость перехода. Keyword/regex intent fallback отсутствует. Ошибки модели, жалобы и read-only ответы не меняют задачи, сессии и таймеры. Исправлены сроки отдыха, учёт результата сессии и подтверждение второй части составного сообщения.
Свежий итоговый полный прогон: **651/651 тестов, 63/63 файла**, exit0, 341.00s (07.10.2026). Целевая регрессия задач: 29/29. Типизация и сборка прошли; git diff --check чист. Расширенный реальный gpt-5.4-mini corpus: **20/20**; доказательства в docs/tasks/SBER500-39-model-proof.json. Это ограниченные synthetic примеры, не универсальная гарантия понимания и не человеческая приёмка.
