## Business outcome
A user can remove a parent and all active descendants, undo exactly that operation,
and retain session history/time. Reliability fix; no measured audience effect.

Scope: minimal cascade fix; reason dialogue/profile investigation remain separate

## Branch and implementation
`fix/sber500-14-task-tree`, final baseline `84f753a` (origin/main).

on `workspace/quntor` and is not included in this fix. Nullable UUID migration; `src/bot/task-tree.ts`
uses the existing owner row lock, traverses inactive intermediate nodes, and blocks
collecting/running/paused descendants. Undo is owner-scoped, durable and idempotent.

paths recheck activity inside their write transaction. Deep descendants are shown.
