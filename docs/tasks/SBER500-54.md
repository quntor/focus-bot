# SBER500-54 — прошедшее время не новый таймер

## Бизнес-результат
Пользователь сообщает уже прошедшее время работы, и ФокусБот не превращает его в будущий интервал. Антон topic753/1186 сообщил «я уже работаю полчаса» → запуск30мин до08:54; topic753/1191 разрешил исправление. Релиз не разрешён.
Plane: https://lifebook.tailce20f5.ts.net:8443/variant/projects/1ad43a9f-a975-40c2-96e7-056ffe0aa4aa/issues/b01aa7f9-89ea-4280-a78d-5019b4dccd72

## Контракт
- Уже прошедшая длительность продолжающейся работы без явного следующего действия → clarify, followUp=null: «Хочешь продолжить — сколько ещё — или отдыхать?».
- Не обещать учёт прошлых минут, не создавать задачу/таймер и не менять существующий.
- «Уже полчаса, ещё15минут» → будущие15, не30/45; «Уже полчаса, теперь отдыхаю5» → отдых5, не done.
- Явный отчёт о законченной сессии остаётся report. Existing retro — коррекция паузы, не восстановление начала работы.
