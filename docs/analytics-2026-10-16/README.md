## Как читать
users.csv подтверждает текущие внешние аккаунты и ever-start/ever-completion; calls.csv содержит модель, время, latency, usage и сопоставленное списание; events.csv — только перечисленные типы событий без payload; daily.csv — дневной учёт компонентов. Метки Pxxx — локальные псевдонимы этой выгрузки. Нет Telegram/user/session ID, имён, текстов задач, сообщений, API-ключей, промптов или чужого биллинга. Событие session_completed означает явное завершение, не гарантирует выполнение задачи. Период — текущий срез после дедлайна, не подменяет состояние15октября23:59.
